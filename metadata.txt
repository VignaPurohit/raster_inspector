about=RasterSample is an interactive geospatial sampling tool built from the FOSS4G "Advanced PyQGIS Scripting and Automation" workshop. Left-click to add vertices, right-click to finish, review mean/min/max/pixel count in the dock panel, then press S to save the polygon (with sample ID and note) to a memory layer or Esc to discard it. Works with QGIS 3.40+ (Qt5) and QGIS 4 (Qt6).
